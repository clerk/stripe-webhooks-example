# Stripe Webhooks Example

A Next.js 16 app demonstrating how to manage Clerk organization membership seats via Stripe subscription webhooks.

When a Stripe subscription becomes active, the linked Clerk organization's `maxAllowedMemberships` is upgraded to 10. When the subscription is canceled or deleted, it's reset to 1.

## Prerequisites

- [Node.js](https://nodejs.org/) 20.9.0+
- [Stripe CLI](https://docs.stripe.com/stripe-cli)
- A [Clerk](https://dashboard.clerk.com/) account
- A [Stripe](https://dashboard.stripe.com/) account (test mode)

## Setup

### 1. Install dependencies

```bash
bun install
```

### 2. Configure environment variables

Copy the example env file:

```bash
cp .env.example .env.local
```

Fill in the following keys:

| Variable | Where to find it |
|---|---|
| `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` | [Clerk Dashboard](https://dashboard.clerk.com) |
| `CLERK_SECRET_KEY` | [Clerk Dashboard](https://dashboard.clerk.com) |
| `STRIPE_SECRET_KEY` | Run `stripe config --list` or visit [Stripe Dashboard](https://dashboard.stripe.com) |
| `STRIPE_WEBHOOK_SECRET` | Generated by `stripe listen` in step 5 (starts with `whsec_`) |

### 3. Start the dev server

```bash
bun dev
```

### 4. Create a test user and organization

1. Open [http://localhost:3000](http://localhost:3000) and sign up
2. Create an organization from the Clerk user menu
3. Go to the [Clerk Dashboard](https://dashboard.clerk.com/) and copy the **Org ID** (starts with `org_`)

### 5. Update the fixture files

Edit `stripe/fixtures/subscription-created.json` and `stripe/fixtures/subscription-deleted.json`:

- Set `metadata[clerk_org_id]` to your Clerk Org ID
- Optionally update the customer `email` to match your Clerk user

### 6. Start the Stripe CLI listener

```bash
stripe login
stripe listen --forward-to localhost:3000/api/stripe/webhooks
```

Copy the `whsec_...` secret it prints and paste it into `.env.local` as `STRIPE_WEBHOOK_SECRET`. Restart the dev server.

## Testing

### Create a subscription (upgrades org to 10 seats)

```bash
bun stripe:sub:create
```

### Delete a subscription (resets org to 1 seat)

```bash
bun stripe:sub:delete
```

Check the Clerk Dashboard to verify the organization's max allowed memberships changed.

## How it works

The Stripe webhook handler at `src/app/api/stripe/webhooks/route.ts` listens for:

- `customer.subscription.created` / `customer.subscription.updated` -- if status is `active`, sets seats to 10. If `canceled` or `unpaid`, resets to 1.
- `customer.subscription.deleted` -- resets seats to 1.

The org is identified via `subscription.metadata.clerk_org_id`, which must be set when creating the Stripe subscription.
